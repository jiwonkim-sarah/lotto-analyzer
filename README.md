# 로또 6/45 5년 통계 분석

최근 5년치 로또 6/45 당첨번호를 분석해 통계 요약과 5가지 전략의 추천 번호 세트를 보여주는 정적 사이트입니다.
**매주 일요일 오후 1시(KST)** 에 GitHub Actions가 자동으로 데이터를 갱신하고 재배포합니다.

> **로또는 매 회차 독립 추첨이며, 이 통계는 당첨 확률을 높여주지 않습니다.**
> 어떤 조합이든 1등 확률은 1/8,145,060으로 동일합니다. 재미와 번호 선택의 참고용입니다.

## 구조

```
scripts/build.py            데이터 수집 · 분석 · 추천번호 생성 (표준 라이브러리만 사용)
docs/index.html             사이트 (의존성 없는 단일 HTML + 인라인 SVG 차트)
docs/data.js                index.html이 읽는 데이터 (window.LOTTO_DATA)
docs/data.json              동일 데이터의 JSON 사본
.github/workflows/update.yml 주간 갱신 + Pages 배포
```

## 데이터 소스

1. **주 소스** — [smok95/lotto](https://github.com/smok95/lotto) 의 전 회차 미러 (`results/all.json`)
2. **보조** — 동행복권 공식 JSON API (`common.do?method=getLottoNumber`)로 미러에 아직 없는 최신 회차를 보강

공식 API는 대기열·봇 차단으로 응답하지 않는 경우가 있어 주 소스로 쓰지 않습니다. 실패해도 미러 데이터만으로 정상 동작합니다.

## 분석 내용

- 최근 5년(약 261회차) 번호별 출현 빈도와 기대값 대비 편차
- 전체 이력 기준 장기 미출현 회차 수
- 동반 출현(궁합수) 상위 쌍
- 당첨번호 합계 분포, 홀짝 비율, 구간별 분포, 연속번호 포함률

## 추천 번호 5세트

최신 회차 번호를 난수 시드로 쓰므로 **회차가 바뀔 때만 번호가 바뀝니다** (같은 주에 여러 번 실행해도 결과 동일).

| 세트 | 방식 |
|---|---|
| 핫 넘버 | 최근 5년 출현 빈도에 가중치 |
| 장기 미출현 | 마지막 출현 이후 지난 회차 수에 가중치 |
| 균형 배분 | 홀짝 3:3, 4개 이상 구간 분산 |
| 궁합수 | 동반 출현 최다 쌍을 축으로 확장 |
| 필터 랜덤 | 무작위 추출 후 통계 필터 통과 |

공통 통계 필터: 합계가 실제 당첨 조합의 중간 80% 구간 안, 홀수 2~4개, 3연속 이상 배제, 3개 이상 구간에 분산, 같은 끝자리 3개 이상 배제.

## 로컬 실행

```bash
python scripts/build.py     # docs/data.js, docs/data.json 갱신
```

`docs/index.html`을 브라우저로 바로 열면 됩니다 (데이터를 `data.js`로 싣기 때문에 웹서버가 필요 없습니다).

## 수동 갱신

GitHub 저장소 → Actions → "주간 갱신 및 배포" → Run workflow.
